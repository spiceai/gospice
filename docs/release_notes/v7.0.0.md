# Announcing gospice v7! 🎉 (Dec 4, 2024)

gospice v7.0.0 allows setting a custom user agent string, adds support for refreshing datasets on a running Spice.ai runtime, and upgrades Arrow to v17.

## What's Changed

- Upgrade to Arrow v16.1 by @lukekim in <https://github.com/spiceai/gospice/pull/49>
- Add support for `/v1/datasets/:name/acceleration/refresh` by @Jeadie in <https://github.com/spiceai/gospice/pull/51>
- add 'refresh_jitter_max' to spice.RefreshDataset by @Jeadie in <https://github.com/spiceai/gospice/pull/52>
- use DatasetRefreshApiRequest directly in SpiceClient.RefreshDataset by @Jeadie in <https://github.com/spiceai/gospice/pull/53>
- feat: add x-spice-user-agent header by @peasee in <https://github.com/spiceai/gospice/pull/55>
- refactor: Delete old functions, rename and move methods by @peasee in <https://github.com/spiceai/gospice/pull/57>
- docs: Add endgame release process by @peasee in <https://github.com/spiceai/gospice/pull/58>
- Adding custom user-agent to gospice by @slyons in <https://github.com/spiceai/gospice/pull/60>
- Prepend the custom user agent to the Go SDK by @phillipleblanc in <https://github.com/spiceai/gospice/pull/62>
